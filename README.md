# Agenda Tattoo

Agenda de citas de Duvan Tattoo preparada como aplicación web instalable.

## Uso

Abra `index.html` mediante GitHub Pages o Cloudflare Pages. En iPhone o iPad, abra la dirección publicada en Safari y seleccione **Compartir → Agregar a pantalla de inicio**.

Las citas se guardan localmente en el navegador de cada dispositivo.
